Input Module

Appeal docsModule standardBasicAdvancedGlobals

Script functions provided by the Input module. Prefix each call with Input; arguments below are consumed in the listed order. Plugin support and behavior may vary.

Basic covers ordinary application and game operations. Advanced covers explicit setup, backend management, and tuning. This classification describes the current API; it does not certify that every backend yet provides the complete Basic-only game workflow required by the standard.

Mouse focus toggle

Set_Focus_Mouse_Button Middle enables middle-click as a focus toggle in both Game and GUI focus. Set_Focus_Mouse_Button None disables it (the default). The configured button is reserved from gameplay mouse getters/callbacks; the transition frame suppresses gameplay input. F1 and controller Back remain available.

Globals

This module does not publish script-visible globals in its current module bridge. Plugin internals and C++ variables are not Appeal globals.

See the focus routing contract and example for reserved toggle controls, state-reset behavior, and SDL2 Graphics/ImGui coordination. GUI input is disabled while Game has focus. Focus is distinct from the Graphics window selection command.

Reference source: module interpreter. Required arguments are not optional defaults. Advanced setup may be performed by Appeal configuration before a Basic script runs.
